# 从零构建 JS ClawHub：纯静态架构下的策展式生态导航实践

> Day 13 · 2026-02-12

面对 OpenClaw 生态中散落的技能与项目，我意识到官方 ClawHub 虽解决了“发布与安装”的闭环，却缺失了“有什么值得关注”的策展入口；今日的核心任务便是确立 JS ClawHub 的差异化定位，以零后端依赖的纯静态架构快速构建这一生态导航站。

## 确立“纯静态架构 + 人工策展”的差异化定位

在构思阶段，我明确拒绝了将 JS ClawHub 做成另一个自动抓取目录站的念头。官方 ClawHub (clawhub.ai) 已经很好地承担了技能注册中心的角色，而新项目的核心价值必须聚焦于"Curation（策展）”。这意味着我们将放弃全自动化的无筛选聚合，转而采用人工精选并附带编辑点评的模式，内容范畴也从单纯的外链扩展至教程、指南、评测及社区动态。为了强化这一技术特征，我将项目命名为"JS ClawHub"，既代表我的 ID (imjszhang)，也直白地宣告了其纯前端 JavaScript 实现、零后端依赖的技术底色，确保与官方平台形成互补而非替代关系。

## 选用原生 HTML 与模块化 JS 构建极简技术栈

在技术选型上，我刻意避开了 React 或 Vue 等重型框架。对于一个以内容展示为主的导航站，原生 HTML 配合模块化 JS 足以胜任，且能显著降低构建复杂度和最终加载体积。我采用了 Neo-Brutalism 设计风格，利用 Tailwind CSS 构建实用优先的响应式系统，并引入 Three.js 为首页打造沉浸式的 3D 动画背景。为了处理文档渲染，我集成了 marked.js 和 highlight.js 实现客户端 Markdown 解析与代码高亮。架构设计上，我严格遵循 `src/`（源码）与 `docs/`（部署产物）分离的原则，所有项目、技能及博客数据均通过 JSON 文件管理，由 HTML 模板负责渲染，从而实现了数据层与展示层的彻底解耦，公共模块如导航栏、页脚及搜索功能则统一收敛至 `shared/` 目录。

## 打造六大核心功能模块并集成 AI 动态筛选

今日首版 v1.0.0 一次性落地了六大核心模块：项目导航、技能市场、博客系统、入门指南、Pulse 动态以及完整的中英双语支持。其中最具挑战性也最具价值的是"Pulse 动态”模块，我设计了利用 AI 每日自动过滤 X/Twitter 社交媒体噪音的机制，仅聚合高价值的 OpenClaw 社区热点。在国际化方面，我自研了轻量级的 `I18nManager`，通过 `data-i18n` 属性驱动 UI 翻译，内容字段采用 `{"zh-CN": "...", "en-US": "..."}` 的双语 JSON 对象结构，Markdown 文档则通过 `.en-US.md` 后缀区分版本。语言偏好被持久化至 localStorage，用户在导航栏一键切换即可实现全站无缝流转。

## 建立标准化 CLI 构建管线与自动化部署流程

为了将“可记录”转化为“可教学”的自动化闭环，我开发了专属 CLI 工具，入口定为 `cli/cli.js`。该工具严格遵循 stdout 输出 JSON 数据、stderr 输出日志的规范。通过执行 `node cli/cli.js sync` 命令，我实现了一键触发包含文件复制、Google Analytics 注入、i18n 翻译完整性校验、Pulse 数据清理及 API 层生成等七步构建流程。该流程自动完成 Git 提交并推送至远程仓库，配合 GitHub Pages 托管 `docs/` 目录及 Cloudflare 免费 CDN 加速，我在创建日当天（2026-02-12）即完成了从 Initial commit 到首版可运行状态的上线，后续更通过该管线快速迭代至 v1.1.0，实现了动态 sitemap 生成与 GA 追踪 ID 的更新。

## 今天的收获

- **差异化定位决定架构复杂度**：明确“策展”而非“聚合”的定位，使得我们可以放弃复杂的后端爬虫，转而采用零成本的纯静态架构，大幅降低维护门槛。
- **原生技术栈的回归价值**：对于内容型导航站，原生 HTML + 模块化 JS 比重型框架更具性价比，既减少了构建体积，又提升了首屏加载速度。
- **数据与展示分离的必要性**：通过 JSON 管理数据、HTML 负责渲染的架构，使得内容更新无需触碰代码逻辑，为后续自动化内容注入奠定了基础。
- **CLI 驱动的工程化闭环**：将构建、校验、提交、推送封装为单一 `sync` 命令，不仅消除了人工操作误差，更让“无人值守”的知识产出成为可能。
- **AI 在信息降噪中的实战应用**：Pulse 模块证明了 AI 不仅是生成工具，更是高效的过滤器，能从嘈杂的社交媒体流中提炼出真正有价值的社区动态。
