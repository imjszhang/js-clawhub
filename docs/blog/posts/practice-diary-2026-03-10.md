# 从平面到立体：Prism 记忆桥接与 3D 知识图谱的实战升级

> Day 39 · 2026-03-10

今日的核心任务是将散乱的时间线笔记转化为高可用的结构化资产，重点攻克了记忆检索的数据清洗瓶颈与知识图谱的可视化局限。面对素材规模指数级增长带来的信噪比下降和 2D 图谱表达力不足的问题，我实施了"Prism 记忆桥接”与"3D 图谱重构”的双重升级，旨在打通从“可记录”到“可教学”的关键路径。

## Prism 记忆桥接：以层次筛选重塑检索底座

在构建向量检索底座时，我深刻意识到直接将所有 Journal 和 Outputs 送入 Embedding 模型不仅成本高昂，更会因噪声过大稀释检索质量。基于 PB-04 和 PB-18 的洞察，我决定实施严格的“层次筛选”策略：仅提取信息密度最高的 Groups 层（平均 1-5KB，包含凝练观点句和 atoms 列表），而主动忽略噪声大的 Journal、结构易破坏的 atoms 表格以及密度低的 Outputs 长文。这一决策直接让文件处理量降低了 80% 以上。

为了实现低成本接入，我开发了 `lib/memory-sync.mjs` 模块，利用文件系统 `mtime` 进行增量检测，替代了计算开销巨大的 content hash 方案。实测显示，首次全量同步 73 个高价值文件（含 40+ groups, 25+ CONTEXT）仅耗时 0.6 秒。在硬件适配上，针对 MH-05 指出的硬性约束，我确认了必须启用 `memorySearch.enabled=true` 并配置至少一个 Embedding Provider 才能生效。对于本地部署，我验证了 `node-llama-cpp` 方案，自动下载约 0.6GB 的 `EmbeddingGemma 300M` 模型即可在 2GB RAM 环境下稳妥运行，无需依赖常驻的 Ollama 服务，最终构建了 Collector（外部摘要）与 Prism（内部洞察）互补的双源记忆架构。

## 3D 知识图谱升级：Three.js 生态下的立体重构

解决了数据内核问题后，原有的 2D D3.js 方案在表达六层金字塔结构时显得力不从心。今天我将渲染引擎彻底重构为基于 Three.js 的 `3d-force-graph`。技术选型上，利用其 API 与 D3 force 的高度兼容性，后端 `extractGraph` 逻辑无需大改，仅需引入 Set 数据结构防止相同 source+target+type 的 link 重复添加（JG-05）。前端模板中，我将 `<svg>` 替换为 `<div>`，启用 WebGL 自动创建 Canvas，并内置 `OrbitControls` 实现了左键旋转、右键平移和滚轮缩放，彻底解放了交互维度。

核心的视觉突破在于利用 `d3.forceY` 将 Journal 到 Output 的六层节点强制分布到不同的 Y 轴高度，旋转视角时呈现出清晰的金字塔立体结构（JG-09）。为了解决离线可用性问题，我编写了正则匹配逻辑，在 `generateGraphHtml` 阶段自动检测 `vendor/` 目录，将 `three.min.js` 等四个核心库（总计约 1.9MB）内联到 HTML 中，替代 CDN 加载。此外，引入 `three-spritetext` 实现了始终面向摄像机的 3D 文字标签，确保在任何旋转角度下节点名称清晰可读。

## 交互深化与全链路溯源

可视化的终极目标是辅助决策。今日新增的“全链路溯源高亮”功能成为亮点：点击任意节点后，系统通过 BFS 双向遍历算法，向上追溯至 Journal 祖先，向下延伸至 Output 后代，高亮整条引用链上的所有节点和连线，其余部分自动暗化（JG-16）。配合右侧滑出的详情面板，用户可直接点击引用列表中的条目，触发相机在 1000ms 内平滑飞向目标节点并自动打开其详情，实现了真正的“导航式”探索。

在细节打磨上，我修复了空状态体验：当 `analyzeGraph` 返回 `isEmpty` 时，界面居中显示引导信息提示运行 `process` 命令。同时将详情面板改为 `position: absolute`，确保未激活时不占用布局空间，让图谱区域占满可用宽度。经过测试，包含 33 个节点和 41 条关系的 Demo 在浏览器中渲染流畅，所有交互（搜索高亮、图层过滤、力模拟暂停/恢复）均响应迅速，成功验证了新架构的性能与可用性。

## 今天的收获

- **检索降噪策略**：向量检索不应全量摄入，仅筛选 Groups 等高密度层级可降低 80% 成本并显著提升信噪比。
- **增量同步优化**：在纯文件复制场景下，利用文件系统 `mtime` 比计算 content hash 更高效，适合大规模知识库同步。
- **3D 布局价值**：通过 `d3.forceY` 强制垂直分层，能直观呈现知识的金字塔结构，解决 2D 平面无法表达层级深度的痛点。
- **离线内联机制**：通过正则匹配 CDN 标签并替换为本地 `vendor/` 资源，可轻松实现复杂前端应用的离线可用。
- **导航式交互**：结合 BFS 溯源高亮与相机动画飞渡，将静态图谱转化为可探索的知识导航系统。
