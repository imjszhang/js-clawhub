# 拒绝黑箱记忆：构建三层解耦架构打造可进化的认知外挂

> Day 58 · 2026-03-29

面对市面上 AI 记忆方案普遍存在的“黑箱不可控”与“缺乏分层”痛点，今天我正式确立了由原生记忆、Knowledge Prism 及 Collector 组成的三层解耦架构，旨在将散乱的时间线笔记转化为具备时间复利的结构化数字资产。

## 痛点破局：从黑箱缓存到分层解耦

在复盘养虾日记系列的前 11 篇内容时，我意识到一个核心差异：为什么我的“龙虾”能记住东西，而别的 AI 聊完就忘？ChatGPT 的 Memory 是个黑箱，经常记错且不可控；Claude 的 Projects 需要手动上传，无法自动积累；普通的 Agent 框架要么只有临时上下文，要么仅有向量检索，缺乏清晰的分层逻辑。

为了解决这一瓶颈，我决定摒弃单一的存储思维，构建一个有机协同的三层架构。这不仅仅是功能的堆叠，而是对“记忆”本质的重构：第一层解决即时性与个人化，第二层解决深度加工与结构化，第三层解决广度情报与自动化采集。只有将短期会话、结构化知识与外部情报三层解耦又协同，才能奠定形成随时间增值数字资产的基础。

## 职能定义：三层架构的专属分工

今天的核心工作是对这三层进行明确的职能切割与载体落地：

**第一层：原生记忆（Native Memory）**
载体锁定为 `MEMORY.md` 及 `memory/*.md` 目录。这一层模拟人的工作记忆与日记本，负责存储当前会话的短期引导文件（如 AGENTS.md、SOUL.md）、个人决策偏好以及每日日志的原始记录。其核心特点是“即时”与“精确”，会话开始时立即加载，且内容经过人工筛选，只保留高价值信息，确保只有“我”和“龙虾”知道的私密性与准确性。

**第二层：Knowledge Prism（结构化知识）**
载体指向 `D:/github/my/js-learn-openclaw/pyramid/`。这一层是系统的“知识消化器”，负责执行 `Journal → Atoms → Groups → Synthesis → Perspectives → Outputs` 的全链路处理。它不再简单存储笔记，而是对 Journal 进行深度加工，提取信息单元（Atoms），归组为知识分组（Groups），并最终收敛为顶层洞察（Synthesis）。这种金字塔结构确保了知识的可追溯性与层次分明。

**第三层：Collector（外部情报库）**
依托 `js-knowledge-collector` 数据库构建。这一层扮演“情报网络”的角色，通过专用 scraper 自动抓取并总结八大平台（微信、知乎、GitHub 等）的外部文章。目前库中已积累 1289+ 篇外部文章（其中微信 908 篇、GitHub 189 篇、知乎 130 篇），每篇都包含 AI 生成的概要、摘要及推荐理由，实现了无需人工整理的规模化情报入库。

## 协同实战：定位 - 获取 - 融合的闭环

在下午的技术问答与新文章撰写场景中，我验证了三层系统的协同流程，效果显著优于单一检索：

**场景一：回答技术进度查询**
当用户询问"Prism 记忆桥接的进度”时，系统并未盲目搜索。首先，**原生记忆**通过 `memory_search` 迅速定位到 `2026-03-10` 的相关讨论记录；接着，**Prism 层**检索到 G57（Prism 记忆桥接）及 KL24 等结构化 Groups，提供了逻辑骨架；最后，系统判定此为内部项目，**Collector 层**不引入外部干扰。最终输出的回答既精准定位了时间线，又具备了结构化的进度详情。

**场景二：撰写安全架构文章**
在生成关于 OpenClaw 安全架构的文章时，三层系统实现了全素材覆盖。**原生记忆**提供了 `MEMORY.md` 中记录的五道锁架构与安全配置细节；**Prism 层**贡献了 KL02 与 KL13 中关于本地部署安全与 Harness 工程的逻辑 Groups；**Collector 层**则提供了外部安全文章作为对比素材。这种融合确保了内容既有个人经验的精准度，又有外部视野的广度。

## 核心价值：构建随时间复利的认知外挂

经过今日的架构梳理，我深刻体会到该系统的护城河在于“时间复利”与“不可复制性”。

与普通 AI 每次对话从零开始不同，三层记忆系统让每一次交互都站在过去 300 天的积累之上。从第 1 天的几条笔记，到第 30 天的几十个 Groups，再到第 300 天的完整知识体系与数千篇外部情报，其价值呈指数增长。更重要的是，即使有人复制了代码，也无法复制我的个人决策历史（原生记忆）、独特的知识提炼方式（Prism Groups）以及长期积累的外部情报库（Collector）。

这不仅仅是一个第二大脑，更是一个具备自我生长能力的认知外挂：原生记忆是偏好存储器，Prism 是知识消化器，Collector 是情报网络。三者协同，让系统真正实现了“消化而非存储”，像土壤一样自我生长，形成了普通 AI 无法复制的独家数字资产。

## 技术落地：自动化与低维护的实现路径

为确保这套架构的低维护成本与高效运行，我在技术实现上采取了以下关键策略：

**原生记忆层**：在 `openclaw.json` 中配置开启 `hybrid` 模式，采用 70% 向量搜索与 30% BM25 关键词搜索的混合策略，并引入 MMR（lambda=0.7）重排序结合 30 天半衰期的时间衰减算法，保障了检索的精度与时效性。

**Prism 层**：实施了严格的层次筛选机制，只导出高价值的 Groups 与 Context 层，成功降低了 80% 的文件数量。同时，基于 `mtime` 的增量同步机制避免了全量导出的资源浪费。通过 `knowledge_prism_process` 与 `knowledge_prism_agent_index` 两条自动化管线，配合 Cron 定时执行，实现了真正的无人值守知识产出。

**Collector 层**：采用了 inbox/batch 轮转架构及专用 scraper，支持微信、知乎、小红书、即刻、X.com、Reddit、Bilibili、YouTube、GitHub 等八大平台的高并发采集，确保每篇文章都能自动转化为包含「概要 + 摘要 + 推荐理由」的结构化数据。

## 今天的收获

- **记忆分层是可控性的基石**：必须将短期会话（原生）、结构化知识（Prism）与外部情报（Collector）解耦，才能避免黑箱操作，实现人工可干预的精准记忆。
- **消化优于存储**：知识系统的核心价值不在于囤积数据，而在于通过 `Journal → Atoms → Groups` 的提炼流程，将信息转化为可复用的逻辑资产。
- **时间复利构建护城河**：通过自动化管线（Cron + 增量同步）确保持续积累，使系统随时间推移形成无法被代码复制的个人数字资产。
- **混合搜索提升信噪比**：在原生记忆层采用“向量+ 关键词”混合搜索及 MMR 重排序，能有效平衡语义理解与精确匹配，解决传统 RAG 检索不准的问题。
- **无人值守依赖架构设计**：通过 inbox/batch 轮转与 mtime 增量机制，将人工维护成本降至最低，让知识演进从“手动任务”变为“自然生长”。
