# 从精确执行到对话策展：18 次迭代重塑 AI 视觉工作流

> Day 54 · 2026-03-25

为了备战周末的 Agent Evolution Hackthon，我今天必须在极短时间内产出符合 Cyber-Taoist Neo-Brutalism 调性的招募海报与视频首帧。面对时间紧迫与风格统一的双重压力，我放弃了寻找设计师或套用模板的传统路径，决定直接利用 JS_Claw 结合 ComfyUI 进行一场“龙虾协作设计”的实时实战，将改图过程本身转化为可记录的演进资产。

## 设计范式的重构：从模板执行到对话策展

在尝试直接复用旧角色图（00184）的提示词生成新素材时，我立刻遭遇了严重的风格偏离与细节失控，新生成的图像不仅面部特征模糊，连核心的品牌色值也发生了漂移。这次踩坑让我意识到，人脑并不擅长记忆长文本参数，且自然语言对视觉的描述存在天然歧义，所谓的“精确执行”在缺乏完整上下文（种子、权重、负面词）时根本无法成立。因此，我果断调整策略，不再追求一次性写出完美提示词，而是转向“对话策展”模式：建立“视觉反馈→语言修正”的闭环，通过 18 轮高频迭代，每轮仅聚焦面部、配色或姿态单一维度，让答案在与人机协作的对话中自然涌现。

## 风格一致性的战术：参数固化与分层控制

为了确保 Neo-Brutalism 风格的精准落地，我首先锁定了生成的“物理基座”：在 ComfyUI 中强制固定采样器为 `res_multistep`、调度器为 `simple`、CFG 设为 1 并限制步数为 9，同时在工作流 `image_z_image_turbo.json` 中明确写入 `photorealistic, 3D render, soft shadows, gradients` 等负面提示词以剔除写实噪点。在具体执行层面，我严格遵循分层递进逻辑处理面部细节：第一层先移除所有遮罩与护目镜（no mask, no visor）以确立亲和力；第二层指定 `natural skin tone` 规避黄色皮肤带来的“黄疸”或过度金属感联想；第三层才微调表情细节。这种拒绝一步到位的粗放式修改，成功解决了角色个性外化的难题，例如通过蓝黑发色定义元气少女，银黑发色刻画高冷御姐，实现了姿态与服装对人物性格的精准区分。

## 视觉闭环的验收：精确色值与自动化归档

在最终的成果验收阶段，我将所有色彩描述从通用词升级为精确色值，强制指定 JS 品牌黄为 `#FCD228`，彻底消除了颜色联想偏差，并将 JS Logo 隐喻性地置于角色胸口能量核心内部，以此传达“能量在内心”的 Cyber-Taoist 理念。经过多轮筛选，文件 `00217` 凭借完整的 facial 展示与完美的能量核心构图，以 4.5/5 的综合评分被确立为海报主视觉，而 `00221` 至 `00224` 则作为覆盖不同开发者个性的备选素材。所有生成文件均按时间戳自动归档至 `D:\.openclaw\work_dir\comfyui_output\` 目录，这不仅完成了单次任务的交付，更将这套包含 18 次迭代轨迹的经验转化为了系统可复用的教学资产，验证了从“可记录”到“可教学”的闭环路径。

## 今天的收获

- **范式转变**：AI 生成工作流的核心已从“精确控制提示词”转变为“基于视觉反馈的对话策展”，迭代过程本身就是设计的一部分。
- **参数铁律**：风格一致性依赖于种子、权重、负面词及采样器参数的完整固化，任何缺失都会导致记忆偏差与风格漂移。
- **分层控制**：复杂的面部与角色调整必须遵循“去遮罩→定肤色→细表情”的三层递进逻辑，严禁试图通过单条提示词一步到位。
- **精确表达**：视觉描述必须摒弃通用形容词（如 yellow），转而使用精确色值（如#FCD228）和具体隐喻位置（如胸口能量核心）以消除歧义。
- **资产沉淀**：通过时间戳自动归档与主视觉甄选机制，将散乱的生成记录转化为结构化的提示词库与自检清单，实现知识资产的自我进化。
